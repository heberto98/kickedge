- Read the existing Phase 4 parquet with an explicit 82-column approved selector. SQL projects targets only for TRAIN 2016–2023, VALIDATION 2024, or final REFIT 2016–2024. Holdout 2025 is count/schema only; never load its labels or predict/evaluate it.

- Numeric medians, missing indicators, categorical one-hot unknown-safe encoding; GLM scaling. Fit preprocessing on TRAIN only during comparison, then refit its frozen recipe on 2016–2024.
- Compare global Poisson baseline, Poisson GLM alpha=0.1 and 1.0, and two Poisson HistGradientBoosting configurations: (leaves=7, iterations=100, learning_rate=0.05, l2=10), (leaves=15, iterations=100, learning_rate=0.05, l2=10). min_samples_leaf=40; no early stopping or random split; seed=42; single-thread execution for reproducibility.
- Decide NB from TRAIN dispersion only. A marginal variance/mean >1.2 warrants further consideration; otherwise no NB. Marginal dispersion alone is not proof of conditional NB need.
- NLL primary; RPS with explicit numerical tail bound; Brier >=2/3/4, MAE, RMSE, Poisson deviance. Calibration: fixed ten equal-width bins, no fitted correction.
- Prefer simplicity: a more complex family replaces the simpler incumbent only with >=1% relative NLL improvement, no >0.002 average Brier degradation and no >0.02 average calibration-error degradation. Select regularization within GLM by NLL. Report uncertainty; this is a practical selection rule, not a significance claim.
- Common Poisson distribution interface with explicit residual tail; exact over/under/push probabilities.
- Diagnostic standardized GLM coefficients or fixed-seed validation permutation importance; never select features from diagnostics.

## Design

- New `kickedge/inference/` package, with a packaged release manifest pinning the
  actual model SHA256 and canonical metadata SHA256 before trusted local joblib
  deserialization. Runtime/source/contract compatibility and fitted recipe,
  exact ordered82 inputs, alpha0.1/refit2016–2024 checked. No historical dataset
  needed in production. Missing/mismatching artifact fails closed; never retrain.
- FeatureSnapshot envelope: `features` (exact82 named JSON fields), `metadata`
  (required kicker/team/opponent; optional kicker_id/game_id/event_id/kickoff/cutoff),
  `provenance` (optional source/snapshot_id/demo/kind). JSON object key order need
  not matter: construct model inputs in the frozen order. Reject extra/omitted
  predictors, booleans in numeric fields, ambiguous numeric strings, NaN/inf;
  accept JSON null only when contract nullable and frozen numeric imputer supports it.
  Integer fields accept finite integral numeric values; boolean fields accept
  booleans or numeric0/1 to accommodate existing materialized snapshots.
- Missing optional metadata produces descriptive warnings. Present malformed
  timestamps or contradictory identities fail. No invented values, opaque
  confidence score or claimed pregame availability certification.
- PropQuote: nonnegative finite integer/half line, side over/under, conventional
  American odds |odds|>=100 (numeric API input; CLI strict signed-integer parsing).
  Optional over_odds and under_odds must occur together and match requested-side
  odds; they describe the same line/event/book snapshot. Do not silently mix prices.
- Conditional no-push probability = win/(win+loss); use it for integer-line
  implied/no-vig comparisons and fair odds. EV always uses unconditional win/loss
  with push return0. Half-lines use direct probability. Fair odds at p=0/1 return
  null plus an explicit endpoint reason; never NaN/Infinity JSON.
- Versioned structured output: model/game/prediction/prop/market/analysis/data_quality.
  DistributionK=12 plus exact tail; warnings include missing metadata, nullable
  inputs and demonstration status. Negative overround is reported, not silently clamped.
- Minimal CLI `python -m kickedge infer --features ... --line ... --side ... --odds ... [--json]`;
  dispatch before historical CLI imports/configuration. Optional metadata args
  must agree with snapshot identity. No API/web server.
- Demo: deterministic feature-only projection of an eligible 2024 kicker-game
  from frozen Phase4 artifact, no target or2025 reads. Store small marked
  DEMO / TEST FIXTURE envelope and source/build/hash trace. Not a current forecast.

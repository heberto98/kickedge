# Phase 4 implementation plan

> Execute with superpowers:subagent-driven-development for independent adapters, then integrate and review. User supplied scope, temporal policy, tests and authorization to commit/push on success.

**Goal:** Market/weather support preserving 82 historical predictors and 5,535 eligible observations.
**Architecture:** Pure builders consume identity/cutoff/evidence. Bounded optional adapters capture current data; deterministic offline sidecars separate training/current/experimental. Frozen Phase 3 files remain unchanged.
**Stack:** Python, DuckDB, requests, python-dotenv, pytest. Existing local workspace as requested.

## Decisions

Market columns: game_spread (negative = kicker team favorite), game_total, moneyline_team/opponent, implied_team_strength (two-way no-vig moneyline probability), implied_game_environment (= total), implied_team_total/opponent_total. Team points = (total - team handicap)/2; opponent = (total + team handicap)/2. Reject negative inferred totals. nflverse spread_line is positive when home favorite: negate for home, retain for away.

Existing schedule closing lines, observed weather and retrospective roof state are experimental. Do not extend the calendar exception. Verified evidence needs source identity/hash and availability <= cutoff < kickoff. Target scores and participation never inform these builders.

Weather: temperature C, wind_speed/gust km/h, precipitation_probability %, precipitation mm, weather_code WMO, roof_type/is_dome. Indoor/closed => outdoor values NULL; unknown roof => no approved exposure assumption. Open-Meteo stitched archives, initialization alone and hindcasts do not prove publication. No bulk unverified historical forecast downloads.

Credentials only in headers, bounded requests, sanitized errors and no automatic costly retries. No ML/UI/deployment/expected kicker/Phase 5.

## Tasks

- [x] Parlay: `kickedge/providers/parlay.py`, `tests/test_parlay.py`. `ParlayClient.current_xpm()` returns normalized observations plus completeness metadata; `current_markets()` captures bounded general market observations. Test price aliases, DFS/sportsbook, missing/invalid sides, secrets, errors/timeout and empty responses before implementation. Calculate American probabilities only for standard sportsbook quotes.
- [x] Weather: `kickedge/providers/weather.py`, `tests/test_weather.py`. `OpenMeteoClient.forecast(latitude, longitude, kickoff)` captures hourly fields. `weather_features(identity, evidence, venue)` returns values/training_eligible/current_usable/reasons/provenance. Test roof exclusion, unknown roof, old valid-time, late issue/capture and observed-vs-forecast before implementation; frozen input produces identical output.
- [x] Market: `kickedge/features/market.py`, `tests/test_market.py`. `market_features(identity, evidence)` and schedule projection. Tests pin home/away signs, no-vig, implied totals, missing/invalid prices, wrong game and future versions before implementation.
- [x] Offline sidecar: `kickedge/features/environment.py`, CLI, `tests/test_environment.py`, contract. Enrich identity-only rows, then preserve frozen baseline unchanged. Explicit opt-in selectors, no experimental input approved. Test all prior values/eligibility preserved, malicious evidence rejected and byte reproducibility.
- [x] Real validation: materialize using existing schedule and Phase 3 only; minimal live smoke tests, full pytest, independent review, secure staging, logical commits, fetch/push main and stop.

## Review focus

No network is invoked by the offline builder or tests.
